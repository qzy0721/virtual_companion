Installation

安装与升级

桌面版按当前用户安装，应用文件与用户数据分开保存，升级不会覆盖角色和历史。

本页目录系统要求安装步骤WebView2目录结构升级卸载校验

系统要求

操作系统Windows 10 / 11 x64
浏览器运行时Microsoft Edge WebView2 Evergreen Runtime
网络访问所配置 LLM、DashScope 和可选 OSS
权限普通用户安装；语音功能需要麦克风权限
磁盘建议至少预留 700 MiB，另加模型、音频和历史空间

安装步骤

  1. 下载当前安装包并核对文件哈希。
  2. 双击安装程序。未签名版本可能触发 SmartScreen，确认文件来源和哈希后再决定是否继续。
  3. 选择安装路径或使用默认路径。
  4. 启动“虚拟陪伴”，在首启向导中配置 API。

WebView2 Runtime

主窗口使用 WinForms + WebView2。Windows 11 通常已经包含 Evergreen Runtime；如果缺失，桌面壳会显示安装入口。安装 WebView2 后重新启动应用即可。

WebView2 只承载主窗口。透明桌宠使用独立 CEF OSR 渲染，两者都访问同一个本地 FastAPI 服务。

程序与数据目录

程序文件

%LOCALAPPDATA%\Programs\VirtualCompanion

用户数据

%LOCALAPPDATA%\VirtualCompanion
├─ .env                 API 与服务配置
├─ backend\data         角色、历史与记忆
├─ prompts              可编辑提示词
├─ reference_audio      参考音频
├─ pet_models           桌宠当前自定义模型
├─ logs\server.log      本地服务日志
└─ WebView2             主窗口浏览器数据

升级

直接运行新版安装包覆盖程序目录。用户数据位于独立目录，正常升级不会删除。涉及配置格式变化时，应用会尽量兼容旧字段，例如旧桌宠正方形 size 会迁移成独立宽度和高度。

卸载

卸载只移除程序文件，默认保留用户数据。如果希望完全清理，请先退出应用并备份需要的数据，再手动处理 %LOCALAPPDATA%\VirtualCompanion。

安装包校验

Get-FileHash -Algorithm SHA256 .\VirtualCompanion-Setup-0.2.0.exe
