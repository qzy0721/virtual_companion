使用要求

  • Windows 10 或 Windows 11，x64 架构。
  • Microsoft Edge WebView2 Evergreen Runtime；Windows 11 通常已预装，缺失时应用会提供安装入口。
  • 至少需要一组 OpenAI 兼容 LLM 配置和 DashScope API Key，才能使用完整对话与语音能力。
  • CosyVoice 声音复刻还需要可公网访问的 OSS 配置；Qwen3-TTS 不要求用户购买 OSS。

安装与升级

  1. 下载安装包并运行，默认安装到当前用户的 %LOCALAPPDATA%\Programs\VirtualCompanion。
  2. 首次启动在配置向导中填写 API 信息，也可以跳过后稍后设置。
  3. 升级时直接运行新安装包即可。角色、配置、历史、记忆和参考音频位于 %LOCALAPPDATA%\VirtualCompanion，安装器不会主动删除。

隐私说明

本项目是本地优先而不是完全离线。角色、历史和配置默认存放于本机；当你使用 LLM、DashScope ASR、TTS 或 OSS 时，完成请求所需的文本、音频或相关数据会发送到你所配置的第三方服务。
