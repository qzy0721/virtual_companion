About the project

关于这个项目

虚拟陪伴是一个由个人持续维护的开发项目。这里不虚构团队背景或发展历程，只展示当前已经实现的产品与工程实践。

A

为什么做

普通聊天页面很难形成“角色就在身边”的感受。我想探索语言、声音、动作、模型和桌面空间能否组合成更自然的陪伴体验。

B

如何取舍

优先把核心链路跑通，再逐步优化透明窗口、托盘、模型同步、状态恢复和设置体验，而不是先搭建庞大的平台概念。

C

数据态度

能够保留在本机的数据尽量留在本机；必须依赖云服务的部分明确说明边界，让用户知道哪些内容会离开设备。

当前技术组成

  • Vue 3、Vite、Three.js、three-vrm：主界面与 3D 模型舞台。
  • FastAPI：本地接口、对话、角色、语音、记忆和桌宠控制。
  • WinForms、WebView2：Windows 主窗口、托盘与本地服务生命周期。
  • CEF C API、Win32 layered window：透明桌宠的离屏渲染与窗口合成。
  • PyInstaller、Inno Setup：本地服务运行时与安装包。

项目状态

当前是持续迭代中的 Windows 单机应用，适合体验和开发验证。它还不是经过代码签名、自动更新、规模化兼容测试和正式支持体系打磨的成熟商业软件。

接下来关注什么

优先改善角色与模型配置的一致性、首次使用引导、服务自检、多显示器与 DPI 适配，以及对话状态反馈。目标不是让功能表更长，而是让已经存在的能力更可靠、更容易理解。
